# Note con API FastAPI — piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (esecuzione nativa, scelta dell'utente) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** un servizio FastAPI + SQLite per le note e tre strumenti dell'assistente (`salva_nota`, `elenca_note`, `cancella_nota`) che lo chiamano con `urllib`.

**Architecture:** pacchetto `note_api/` indipendente (archivio SQLite + app FastAPI + avvio uvicorn). Nell'assistente un modulo `assistente/note.py` con il wrapper HTTP e la fabbrica degli strumenti; errori come `ToolException`, che `nodo_strumenti` trasforma già in `ToolMessage` d'errore. Il grafo non cambia: una regola nel prompt, gli strumenti in `__main__.py`, un avviso se il servizio non risponde all'avvio.

**Tech Stack:** Python 3.14.7, `fastapi==0.162.2`, `uvicorn==0.54.0`, `sqlite3`, `urllib.request`, `langchain_core`, pytest (`fastapi.testclient`, che usa `httpx` già installato con `mcp`).

**Spec:** `docs/superpowers/specs/2026-11-09-note-design.md`

## Global Constraints
- In `assistente/` niente import di `openai`, `httpx`, `pydantic`, `fastapi`, `uvicorn`; `note_api/` non importa nulla da `assistente/`.
- Nuove dipendenze solo `fastapi==0.162.2` e `uvicorn==0.54.0` in `requirements.txt`; dopo l'installazione `pip check` pulito.
- Nuova variabile dell'assistente `NOTE_API_URL` (default `http://localhost:8000`); del servizio `NOTE_DB` (default `dati/note.db`), `NOTE_HOST` (default `127.0.0.1`), `NOTE_PORT` (default `8000`).
- Testo della nota: `strip()`, da 1 a 500 caratteri. Elenco: al massimo 20, dalla più recente. Timeout HTTP 5 s.
- Messaggi verso il modello in italiano; mai il testo di validazione di FastAPI/pydantic né tracce di `urllib`.
- Branch `feature/note`; Conventional Commits in italiano con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; `git status`, diff, staging selettivo. `dati/` mai versionata. Niente merge né push.
- Prove da pipe senza `PYTHONIOENCODING`, in una PowerShell pulita (script UTF-8 con BOM nello scratchpad).

## Review Focus
1. Servizio spento: avvio dell'assistente senza blocco (solo un avviso) e strumenti con «servizio note non raggiungibile …». Test in Task 2 e 3.
2. Testo con soli spazi o di 501 caratteri; `numero` non intero (`"tre"`, `2.5`) nel percorso o nello strumento: errore in italiano, mai 422 grezzo. Test in Task 1 e 2.
3. Ricerca senza distinzione di maiuscole e con caratteri accentati (`Microscopio`, `perché`). Test in Task 1.
4. Più di 20 note: elenco di 20 con «mostrate le 20 più recenti su N». Test in Task 1 e 2.
5. Numero non riusato dopo una cancellazione; note presenti dopo la riapertura del DB. Test in Task 1.
