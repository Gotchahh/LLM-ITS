# Revisore della risposta — piano di implementazione

> **Esecuzione:** superpowers:executing-plans, task per task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** un nodo LLM `nodo_revisore` dopo la risposta dell'agente che la rimanda indietro con il motivo se non è coerente, fino a `REVISIONI_MAX` volte, e una cronologia finale con la sola risposta approvata.

**Architecture:** `assistente/revisore.py` contiene schema, messaggi per il revisore, lettura della valutazione e testo dell'indicazione. In `costruisci_grafo` il revisore si attiva solo se riceve le istruzioni: la risposta senza strumenti va a `nodo_revisore`; se non è coerente sotto il limite si aggiunge un'indicazione (un `HumanMessage` marcato) e si torna a `nodo_llm`; altrimenti `nodo_pulizia` rimuove bozze e indicazioni con `RemoveMessage` e il turno finisce. Il revisore usa lo stesso client senza ragionamento del router (`crea_modello_router`).

**Tech Stack:** Python 3.14.7, LangGraph (`add_messages`, `RemoveMessage`), `langchain_core`. Nessuna dipendenza nuova.

**Spec:** `docs/superpowers/specs/2026-11-09-revisore-design.md`

## Global Constraints
- Output del revisore: `{"coerente": boolean, "motivo": string}` (schema dizionario, title `valutazione_revisore`), `method="json_schema"`, `include_raw=True`.
- Log: `revisore: coerente (<motivo>) in N s`; `revisore: non coerente (<motivo>), revisione 1 di 2 in N s`; WARNING `revisore: limite di revisioni raggiunto, si restituisce l'ultima risposta`; WARNING `revisore: errore (<Tipo>), la risposta è approvata`; WARNING `revisore: valutazione illeggibile, la risposta è approvata`; `nodo_pulizia: rimossi N messaggi di revisione`.
- Variabili: `REVISORE_FILE` (default `revisore.txt`), `REVISIONI_MAX` (intero ≥ 0, default 2).
- `LIMITE_PASSAGGI = 20` (10 per l'agente e gli strumenti, più router, revisioni e pulizia).
- Nessun import di `pydantic`, `openai`, `httpx` in `assistente/`.
- Branch `feature/revisore`; Conventional Commits in italiano con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; staging selettivo; niente merge né push.

## Review Focus
1. Revisione dopo un turno con strumenti: bozza rimossa, messaggi degli strumenti conservati, nessun `ToolMessage` orfano. Test in Task 2.
2. Più turni di fila: la domanda revisionata è l'ultima vera domanda dell'utente, non l'indicazione; nessuna indicazione nei turni successivi. Test in Task 2.
3. `REVISIONI_MAX=0`: il revisore viene chiamato una volta e la risposta resta anche se non coerente. Test in Task 2.
4. Rifiuto del router: nessuna chiamata al revisore. Test in Task 2.
5. `REVISIONI_MAX` non numerico o negativo: errore all'avvio, nessun traceback. Test in Task 1.
